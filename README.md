# [To-Do List Project](https://jinuine505.github.io/ToDo-List/)
A straightforward to-do list allowing users to store and track their tasks.

## Features
* Tasks
  * Add tasks
  * Delete/Clear tasks
  * Mark/Unmark completed
  * 25 task limit
* Validated inputs
  * Non-empty input
  * Contains no non-standard characters
  * No duplicate tasks
  * 55 character limit
  * Error message for non-compliant input
* Progress tracking
  * Progress bar
  * Task count
* Desktop and mobile viewing
* Saving to local storage

## Library
1. [Font Awesome](https://fontawesome.com/) - An icon library and toolkit for the icons in this project

## Running Locally
Prerequisites
* Recommended: [VS Code](https://code.visualstudio.com/) with [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension by Ritwick Dey for full functionality
1. Clone the repository
 
```bash
git clone https://github.com/jinuine505/ToDo-List.git
cd ToDo-List
```
2. Open the project in VS Code:
   
```bash
code .
```
3. Start the live server<br />
* Right-click on index.html and choose "Open with Live Server"<br />
or<br />
* Click the "Go Live" button in the bottom-right corner


## Using The To-Do List
1. Enter your task in the text field
2. Press the add button or hit enter/return on your keyboard
3. Track and mark your tasks as completed
4. Finished or unwanted tasks can be deleted, or optionally, the entire list of tasks can be cleared
